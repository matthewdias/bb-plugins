## How it works

Every plugin you install can add a control to the thread header, a banner
above the composer, or a button on every message, and bb shows all of them.
Declutter gives you a switch for each one, bb's own included. Switch one off
and it is gone in every window.

## What you get

**One list for three places.** Thread header controls, banners above the
composer, and message actions, each with a switch. Plugin controls show which
plugin they come from.

**Beside the thread or in Settings.** Open the list from the palette or the
right panel and the thread stays in view, so you see each switch take effect.
It is also on the plugin's settings page.

**The same everywhere.** What you hide is kept on the server, so every window
and device agrees, and a reload hides things at once.

**Fills itself in.** Each window notes what it has on screen, so the list grows
as you use bb. Nothing to type.

## Good to know

Hidden is not disabled: the plugin still runs, and its shortcuts and commands
still work. Banners go by plugin, and bb's own banners are not listed. Hiding
relies on markers bb puts in its markup; if a release renames one, that item
simply shows again.
